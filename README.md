# 🌍 WorldSense

**WorldSense** is a modern web application designed to make learning about countries engaging, interactive, and enjoyable through real-time data, media, and gamified experiences.

---

## 🚀 Live Demo

👉 https://worldsense.vercel.app

---

## 📌 Overview

WorldSense allows users to:

* Discover countries using geolocation
* Learn key information (capital, language, etc.)
* Explore real-time weather data
* View country images and travel videos
* Save and manage favorite countries
* Track learning progress
* Take interactive quizzes

---

## ✨ Features

### 🌐 Home Page

* Detects user location, search, and map interaction
* Displays:

  * Country information
  * Weather data
  * Images (Unsplash API)
  * Travel videos (YouTube API)
* Handles loading and error states

---

### ⭐ Favorites System

* Save countries with:

  * Visited status
  * Personal notes
* Search, sort, and manage saved data

---

### 🧠 Quiz System

* User authentication (currently localStorage-based)
* Quiz dashboard with:

  * XP points
  * Daily streak
  * Learning progress
* Multiple categories and difficulty levels

---

### 📚 Learning System

* Structured flow:

  * Not Learned → Learning → Learned
* Quiz-based progression with accuracy requirement

---

### 👤 Profile & Stats

* User level and XP
* Quiz performance
* Accuracy tracking
* Activity insights

---

## 🧩 Tech Stack

* HTML, CSS, JavaScript
* React.js
* REST APIs:

  * Countries
  * Weather
  * Unsplash
  * YouTube

---

## ⚠️ Current Limitations

* Authentication is client-side (localStorage)
* No backend integration yet
* Limited scalability in current version
